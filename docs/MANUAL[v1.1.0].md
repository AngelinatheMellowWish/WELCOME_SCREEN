## 1. 安装与首次运行

### 1.1 系统要求
| 项 | 要求 |
|----|------|
| 操作系统 | Windows 10 / Windows 11（64 位） |
| 运行库 | **无需安装**（程序自包含 .NET 8 运行时，目标机无需装 .NET） |
| 磁盘 / 内存 | 约 700MB 磁盘（自包含发布，含 .NET 运行时，解压后）；空闲内存目标 ≤250MB（多进程合计） |

### 1.2 获取与安装（零基础）
1. **获取发布包**：从 GitHub Releases 下载发布压缩包并解压（或从源码构建，见 `README`）。发布包内含主程序与子进程：
   `Object1688.Main.exe`、`Object1688.Overlay.exe`、`Object1688.Monitor.exe`、`Object1688.Logging.exe`、`Object1688.ConfigUI.exe`，以及 `config/`、`resources/` 等。
2. **放到任意目录**：建议 `C:\Object1688` 或用户目录。**请整体保留该文件夹**（五个进程需在同一目录，勿只复制单个 exe）。
3. **无需安装器**：绿色软件，双击 `Object1688.Main.exe` 即运行。

### 1.3 首次运行
1. Windows 若弹出 **SmartScreen"未知发布者"**：本版未做代码签名，属正常——点"更多信息 → 仍要运行"（详见 §5）。
2. 程序**没有主窗口**，启动后常驻**系统托盘**（右下角）；首次启动会弹一次气泡引导。
3. 首次启动会按配置显示一次**欢迎大字**（可在配置窗口关闭）。
4. 右键托盘图标 →「设置…」打开配置窗口，按 §2 快速上手添加第一条规则。

> **Windows 11 提示**：新出现的托盘图标可能被收进右下角 **`^`「隐藏的图标」**里——用鼠标把它拖到任务栏即可固定。若一时找不到图标想退出程序，**双击发布目录下的 `build\quit.cmd`** 即可（无需点托盘图标）。

### 1.4 开机自启
程序**默认随系统登录自动启动**（写 `HKCU\...\Run`，可关）。开关位置：配置窗口 →「勿扰/提示音/自启」页。移动程序后若自启路径失效，启动会托盘提示（PRC-W-2006），重新开启自启即可修复。

### 1.5 卸载
1. 托盘右键 →「退出」（或"退出并取消开机自启"）。
2. **双击发布目录下的 `build\uninstall.cmd`**（删除自启项 + 清理 `%APPDATA%\Object1688`；命令行加 `-AlsoCleanLogs` 可同时清日志），或手动删除发布文件夹与 `%APPDATA%\Object1688`。
   > `.ps1` 在 Windows 11 默认用记事本打开，故随包提供 `.cmd` 以便双击运行。

## 2. 快速上手

1. 运行程序后，图标出现在**系统托盘**（右下角）；**左键**单击弹快捷菜单（手动大字 / 暂停·恢复）、**双击**打开配置窗口、**右键**完整菜单、**悬停**显示运行状态；右键菜单含「打开日志文件夹」「复制最近错误码」（AC-93），点击错误气泡亦可打开日志
2. **手动大字**：右键托盘图标 →「手动大字」→ 屏幕浮现手动大字（内容可在配置窗口"手动大字"页定制；快捷键默认 Alt+F，可改/禁用）
3. **添加触发规则**：右键托盘 →「设置…」打开配置窗口
   - 在「触发规则」页点击工具栏"**＋新建**"（或列表旁新建）；熟手可直接编辑表单
   - 选择匹配类型（进程名 / 窗口标题）与匹配模式（完全 / 包含 / 通配）
   - 填写匹配值（如 `chrome.exe` 或 `*游戏*`）
   - 填写显示文字（可多行，支持 `{appName}`/`{time}` 变量）、出现延迟（秒）、保持时长（秒）
   - 可选：设置描边颜色防撞色；预览区实时查看
   - 点击"**测试显示**"在真实屏幕试看 → 保存 → 立即生效（热生效广播）
4. **验证**：启动对应程序，数秒后出现大字（注意勿扰/暂停状态会抑制自动大字）

> 说明：**新建向导、样式预设套用、预览拖拽定位、性能窗口图表（排行/24h）**均已提供；详见配置界面说明。

## 3. 配置界面说明

配置窗口（托盘「设置…」）采用**页签**布局，顶部工具条常驻"新建规则 / 新建向导… / 删除规则 / 恢复默认 / 导入… / 导出… / 冲突检测 / 测试显示 / 保存"：

| 页签 | 说明 |
|------|------|
| 触发规则 | 左列规则列表 + 右列编辑：匹配类型/模式/值、显示文字（多行）、延迟/保持、字号、位置、描边、**样式预设套用**；列表支持搜索/复制/↑↓ 排序/全部启停，Ctrl+Z/Y 撤销重做 |
| 欢迎大字 | **程序每次启动**显示的欢迎大字（可开关、独立文字行/字号/延时/保持） |
| 手动大字 | 托盘/快捷键手动触发显示的文字（可开关、独立配置，可设快捷键） |
| 勿扰/提示音/自启 | 全局暂停、定时勿扰开关、**投屏/演示自动静默开关**；提示音（system/custom 音源 + 音量 + 自定义 wav/mp3 路径）；开机自启开关 |
| 使用说明 | 内置帮助（操作指引 + 隐私说明） |

> 保存经校验 → 原子写盘 → 主进程广播热生效；**关闭窗口 / 切换规则**时若有未保存修改会先提示「保存 / 放弃 / 取消」，恢复默认也会先确认未保存修改（AC-38）。

### 描边色 / 描边宽度怎么填
- **描边色**（给白色大字加一圈边，防止在浅色背景上看不清）：点「**常用色**」色块一键选择，或点「**选择颜色…**」用 Windows 系统取色器；也可手填 `#RRGGBB`（`#000000` 黑 / `#FFFFFF` 白 / `#FF0000` 红…）；**留空 = 跟随全局默认**（点「**跟随全局**」即清空）。
- **描边宽度**：像素数，`0` = 不描边（一般 2–6）。**描边方式**：柔光（方案A，开销低）/ 精确（方案B，更清晰）。

## 4. 性能监控窗口

- 位置：托盘菜单 →「性能窗口…」
- 显示：CPU %（各进程曲线，60s/5min 切换）、内存 MB 曲线、**动画帧率曲线**、进程状态表、检测事件流（环形 500）、触发统计（累计持久化计数）、**规则触发排行 Top5 条形图 / 24h 时段分布图**、**最近一次大字回看 + 最近渲染开销**（时间/规则/文字、CPU/内存增量，AC-63/68/92/95）
- 窗口关闭=隐藏（Monitor 常驻采集），可从托盘再次打开；窗口位置/时间窗自动记忆
- 导出：性能采样 CSV（UTF-8 BOM）/ 事件 CSV / 事件 TXT / 统计 JSON → `log/exports/`
- 清除：一键"清除历史"（事件流 + 持久化触发统计）

> 一键诊断包：托盘右键 →「导出诊断包…」或脚本 `--control diagnostics`，生成 `log/exports/diagnostics-*.zip`（日志 + 配置 + 统计 + 环境信息，AC-83）。

## 5. 疑难排解

| 问题 | 处理 |
|------|------|
| 找不到托盘图标 / 无法退出 | Windows 11 可能把图标收进右下角 `^`「隐藏的图标」（拖出即可固定）；也可**双击发布目录 `build\quit.cmd`** 直接退出（或 `--control quit`） |
| 大字没有出现 | 检查规则是否启用、匹配值是否正确；确认是否处于"勿扰/暂停"状态；打开性能窗口查看事件流 |
| 大字看不清 | 在规则编辑中开启描边并选择高对比颜色，或直接套用「样式预设」（高对比/影院深底等，F-23/AC-60） |
| 误触发想立即关掉 | 再次按下手动触发快捷键（默认 Alt+F）可提前结束当前大字（F-07）；或经脚本 `--control end` 结束 |
| 快捷键没反应 | 确认配置中手动快捷键未被清空；若被其他程序占用，注册会失败并托盘提示（AC-71），可在配置窗口更换 |
| 全屏游戏中无效果 | 部分独占全屏应用需兼容设置（尽力置顶，失败自动记录日志并降级），见配置窗口说明 |
| 提权窗口（管理员程序）上无大字 | 程序以当前用户权限运行，无法覆盖提升完整性级别的窗口；命中时会记录 OVL-W-3008 并托盘提示一次（AC-94） |
| 启动后提示"某项能力不可用" | 程序启动自检失败进入降级运行：按提示修复（如恢复默认配置/重装字体）后重启 |
| 中文显示为方框/乱码 | 正常应回退系统中文字体；若仍异常请反馈（嵌入字体仅含西文字形，中文依赖系统字体） |
| 程序崩溃 | 转储文件在 `log/crash/`（自动保留最近 10 个或 ≤200MB）；日志在 `log/`；提交 [错误码](error_codes[v1.1.0].md) 反馈问题 |
| 想提交完整现场 | 托盘「导出诊断包…」或脚本 `--control diagnostics`：生成 `log/exports/diagnostics-*.zip`（日志 + 配置 + 统计 + 环境信息，AC-83） |
| 想恢复默认 | 配置窗口顶部「恢复默认」（未保存修改会先确认），或删除 `%APPDATA%\Object1688\config.json` 后重启 |
| 想清除记录 | 性能窗口「清除历史」清空事件流与持久化触发统计；日志文件可手动删除 `log/*.log`（或运行 `build/uninstall.ps1 -AlsoCleanLogs`） |
| SmartScreen 提示未知发布者 | 本版本未做代码签名：点击"更多信息 → 仍要运行"；长期使用可信任该 exe |
| 移动 exe 后不自启 | 启动时检测自启注册项是否指向当前 exe；失效会托盘提示（PRC-W-2006，AC-53），在配置窗口关闭后重新开启自启即可修复 |
| 彻底卸载 | 运行 `build/uninstall.ps1`（删除自启项 + `%APPDATA%\Object1688`，可选清日志）或按手册清理 |

## 7. 常见问题（FAQ）

**Q：程序会联网吗？会上传数据吗？**
A：不会。纯本地运行，不联网、不上传任何数据（详见下方"数据与隐私说明"）。

**Q：托盘图标为什么有时会变色或弹气泡？**
A：图标随运行状态切换（正常/暂停/勿扰/错误，AC-62）；发生致命错误时会弹一次含错误码的气泡，点击气泡可打开日志文件夹（AC-93）。

**Q：大字能覆盖全屏游戏或管理员窗口吗？**
A：全屏应用尽力置顶，但独占全屏可能无法覆盖（记录日志并降级）；提权窗口（管理员程序）无法覆盖，会提示一次 OVL-W-3008（AC-94）。

**Q：`{appName}` 和 `{time}` 变量怎么用？**
A：显示文字中写 `{appName}` 会替换为命中的进程名/窗口标题；`{time}` 替换为触发时刻，格式由全局 `timeFormat` 决定（auto / HH:mm / HH:mm:ss / datetime / 24h）。

**Q：怎么让某条规则只在指定显示器显示？**
A：在规则编辑中设置"目标屏"（primary 或指定序号）；多显示器下大字显示在指定屏（AC-24）。

**Q：怎么临时不弹大字？**
A：托盘左键/右键「暂停」；或启用"定时勿扰"；投屏/演示时可开"自动静默"（AC-90）。

**Q：配置改错了怎么回退？**
A：配置窗口「恢复默认」，或删除 `%APPDATA%\Object1688\config.json` 后重启；导入前会自动备份到 `config.bak1..3`。

**Q：默认快捷键是什么？能改吗？**
A：手动大字默认 `Alt+F`（可在配置窗口"手动大字"页修改或禁用）；若被其他程序占用，注册会失败并托盘提示（AC-71）。

### 数据与隐私说明
- 本程序**纯本地运行**：不联网、不上传任何数据
- 日志/事件流会记录命中的进程名与窗口标题（仅用于触发排障），全部保存在本机 `log/` 与 `%APPDATA%\Object1688`
- 如需清除记录，使用配置界面/性能窗口的"清除历史"功能

### 命令行参数
- `--config <路径>` 指定配置；`--lang <zh-CN|en-US>` 覆盖语言；`--debug` 调试日志；`--no-autostart` 便携运行；`--version` 查版本

### 脚本控制接口（外部调用）
程序运行期间，可用其他脚本调用其功能（**仅当前用户可访问**，不联网）：

**方式一：命令行封装（推荐）**
```
Object1688.Main.exe --control status
Object1688.Main.exe --control banner --text "Hello 世界"
Object1688.Main.exe --control pause
```
- 支持命令：`ping` / `status` / `banner`（`--text` 文字、`--screen` 目标屏）/ `manual` / `pause` / `resume` / `toggle-pause` / `end` / `reload` / `config` / `perf` / `about` / `diagnostics` / `quit`
- 结果以 JSON 打印到标准输出；退出码 `0`=成功、`2`=命令失败（响应含错误码）、`3`=主实例未运行

**方式二：命名管道 JSON**
- 连接 `\\.\pipe\Object1688.control`，发送单行 JSON 请求，读取单行 JSON 响应
- 请求示例 `{"command":"status"}`；`banner` 请求示例 `{"command":"banner","text":"Hello\n世界","targetScreen":"primary"}`
- 响应示例 `{"ok":true,"data":{...}}` 或 `{"ok":false,"errorCode":"IPC-E-7005","message":"..."}`

> **完整 API 说明**（全部命令与参数、请求/响应字段、PowerShell/Python 示例、退出码与错误码）见项目根目录 **[`API调用说明.md`](../API调用说明.md)**。
